# @yuzur1ha/press-reference

Add interactive component demos, source previews and API tables to YuPress documents. Use the reference renderer with the default theme or supply your own site layout.

Wrap a reference page in `<ReferenceMessagesContext value={{ sourceLanguage: "Example source", property: "Prop" }}>` to customize demo, metadata and API table labels. Omitted labels inherit the site messages or their English defaults.

# Markdown

`@yuzur1ha/markdown` compiles individual Markdown documents into React ESM at build time. No parser or AST interpreter runs in the browser. Use it in an existing application without installing YuPress, UI or a theme.

## Choose a guide

- [Getting started](/markdown/getting-started/): installation and a complete compiler example.
- [Compiler and metadata](/markdown/compiler/): options, output, errors and HTML boundaries.
- [Plugins and extensions](/markdown/plugins/): directives, AST plugins and standard element renderers.
- [Vite integration](/markdown/vite/): transforms, cached results and TypeScript declarations.
- [Typography](/markdown/typography/): scoped styles and visual examples.

## Use YuPress for a site

The compiler reads source text and returns code, metadata, source maps and dependencies. File discovery, content policies, watching, navigation and output are host responsibilities. [YuPress](/press/) supplies those services and standard code-block highlighting/copying while keeping the compiler independently usable.

# Yuzur1ha Docs

## A system made to be used.

Good interfaces come from small decisions made consistently. These documents bring together the tokens, components and publishing tools behind Yuzur1ha, with working examples close to the ideas they explain.

Start with [Foundations](/ui/foundations/) to understand the visual language. Explore a component, read its source, then take the same primitives into your own application.

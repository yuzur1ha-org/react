# Workflow rules

Use stable `oss-migration:REQ-*` and `oss-migration:TASK-*` identifiers. Record requirement/API changes, implementation and actual acceptance separately. UI design is needed for visual behavior changes; backend API/database artifacts are N/A. Features use Draft/In review/Approved/Implemented/Verified; ADRs use Proposed/Accepted/Rejected/Superseded. Do not equate file existence with completion.
